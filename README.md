# Oro Barber Website

Create the website for Oro Barbershop (from repository oro-barber-appointments). It is a stylish barbershop at Norkkokuja 3. 

Key details and sections:
- Header: Brand logo text "ORO BARBERSHOP", navigation links (Palvelut, Ajanvaraus, Sijainti), call-to-action button to call "041 796 2012"
- Hero section: Bold headline "Terävä tukka. Ei kiemuroita.", subtitle explaining haircuts, fades and shaves, address badge "Norkkokuja 3", and action buttons for "Varaa aika: 041 796 2012" and Instagram (@orobarbershop2)
- Services (Palvelut):
  1. Hiustenleikkaus ("Klassinen leikkaus tai moderni fade — aina siisti lopputulos.")
  2. Parranajo & muotoilu ("Perinteinen partaveitsiajo ja parran trimmaus tarkalla kädellä.")
  3. Muotoilu & viimeistely ("Viimeistele look laadukkailla tuotteilla ja tyylillä.")
- Appointment & booking section (Ajanvaraus): Easy booking by phone ("041 796 2012", call button), card highlighting "Walk-in tervetullut" (walk-ins welcome without reservation) and Instagram link (@orobarbershop2)
- Location & Contact (Sijainti): Address Norkkokuja 3 with link to Google Maps, embedded Google Map iframe, phone number
- Footer: Logo, address, phone number, and Instagram link
- Modern dark theme with gold/amber accent colors and clean typography.
